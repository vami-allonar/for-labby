## Open it now

1. Unzip the downloaded ZIP file.
2. Open the folder `for-labby-website`.
3. Double-click `index.html`. It opens in Microsoft Edge (or your default browser).
4. Click **play our song** for the gentle original instrumental. Browser policies require a click to start audio.
5. Click **Open my letter to you** or the envelope to read the letter; tap memory cards to enlarge them.

## Music

The website already includes an **original, gentle instrumental** named `assets/audio/for-labby-original.mp3`, composed for this site. This is **not a Taylor Swift recording**.

To use a different instrumental that you have permission to publish:
1. Replace `assets/audio/for-labby-original.mp3` with a licensed file using the same name.
2. Reload the site. The play/pause control will work as before.

Please don't upload a copyrighted Taylor Swift instrumental to a public website unless you have the rights or permission needed to do so.

## Customize wording or photos

- `index.html`: names, love letter, messages, and captions.
- `style.css`: colors, fonts, appearance.
- `script.js`: interactive features and date countdown.
- `assets/illustrations/`: local decorative artwork. No photo-service subscription needed.

## Publish with GitHub + Vercel

1. Create a new GitHub repository (e.g., `for-labby`).
2. Upload the **contents** of this `for-labby-website` folder (keep the `assets` folder).
3. In Vercel, choose **Add New → Project**, import that repository, and deploy.
4. For a static site, Vercel usually detects it without special build configuration. If asked, use **Framework Preset: Other** and leave the build command empty; set Output Directory to `.` if required.
5. Visit the generated public URL on your phone to test the photo gallery, letter, countdown, and music.

**Website files are fully static.** No npm install, backend, account, or API is required. Google Fonts may need internet; the site has built-in font fallbacks.
